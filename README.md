## Bag Boutique 
A game made for the [girly game jam](https://itch.io/jam/-girly-game-jam-3-1).
This is a sort of dress up game, where you can customize bags to the preference of different customers.
There are 3 different bag models, which are colorable, and 11 colorable trinkets too.
10 different customers (levels).
Peresistents audio prefences is saved between sessions.

Play on [itch.io](https://johnatan-n.itch.io/bag-boutique), or download for windows.
